# Pannel Handle 样式维护

开始样式任务时读取仓库根目录的 [CSS 与界面样式规范](../../../docs/css-style-guide.md)，作为唯一详细规范来源。该路径相对于本技能目录；仓库根目录位于本目录的 `../../..`。

- 根据任务定位桌面端 `src/` 或移动端 `mobile/src/` 的组件、现有样式与变量；先复用已有规则，再决定是否新增。
- 区分规范中的当前结构、后续要求和推荐值。按任务范围渐进应用，不自动重写历史 CSS、迁移移动端主题或引入样式工具。
- 桌面端沿用分层入口和语义主题变量；移动端保持现有样式归属与安全区、底部输入区行为。
- 修改公共类前检查引用，避免影响其他功能；动态尺寸和静态外观按规范分别处理。
- 完成后执行规范中适用的验证，并分别说明自动验证和实际视觉验证的范围。

仅修改业务逻辑、后端、文档等不涉及界面样式的任务无需读取本技能。用户明确指定的任务范围和视觉要求优先。
