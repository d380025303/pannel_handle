# 会话环境变量

在“设置 → 环境变量配置组”中创建配置组，填写变量名和值，保存后在创建或编辑会话的“环境变量”区域选择。每个会话最多选择一组，可以添加同名会话变量覆盖组内值；预览显示待注入值与来源。组内修改在下一次启动会话时生效。

批量粘贴接受每行 `KEY=VALUE`，按第一个等号分隔，忽略空行及以 `#` 开始的注释行。值按原文保存，包括引号、空格、美元符号与后续等号；不执行插值或命令。空字符串表示设置空值，不表示删除变量。

优先级：进程继承环境 → 配置组 → 会话覆盖 → 应用内部运行变量。Windows 按不区分大小写合并，WSL 和 Linux 按区分大小写合并。应用保留 `PANNEL_HANDLE_*` 和 `WSLENV`；模型服务的运行时变量具有最终优先级。

Windows 注入当前终端进程；WSL 通过 WSLENV 传递原始值，不转换路径；SSH 远端注入要求 Linux、`/usr/bin/env` 和 `/bin/bash`，以交互登录 Bash 启动，不依赖 SSH 环境变量接收配置。Shell 启动文件仍可覆盖注入值。SSH 本地 Agent 模式只注入本地 Agent，SFTP 和独立后台远程命令不继承。

配置组文件 `environment-profiles.json` 保存在 Electron userData 目录，会话覆盖随会话配置保存。第一版仅用于普通配置，明文保存，不提供密钥存储。被引用的配置组不能删除。会话导出将选中组与覆盖合并为变量快照，导入后不依赖原机器的配置组。
