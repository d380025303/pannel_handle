# 项目模块负责人

最顶部标题栏点击「模块负责人」，按会话模板查看和维护模块名称、职责和主要负责目录。目录每行一个，按模板项目工作目录保存为相对路径。相同目录的不同模板仍维护独立负责人表。

页面可编辑会话模板、Plan／正常模式及生成提示词，默认 Plan、模型继承模板。点击「保存生成配置」可保留当前模板的模式与提示词；开始生成也会保存配置。内置接口与工具参数可展开查看，凭据脱敏。

生成需要开启 HTTP 接口服务，并使用有项目目录的本机 Windows Codex 图形模板。页面通过主进程真实请求 `POST /api/v1/session-instances`，创建一个分析会话，附加当前完整负责人表，注入 `list_module_owners`、`add_module_owner`、`update_module_owner`、`delete_module_owner`。不支持的模板仍可手工维护表格。

AI 自行决定增删改，通过内置 `/api/v1/module-owner-tools` 回调写入。`list_module_owners` 接受可选 `name`（1～200 字符，去除首尾空白后按模块名称精确匹配），例如 `{ "name": "桌面界面" }`；不传则返回当前模板全部负责人，未匹配返回空数组。新增接受 `name`、`responsibilities`、`directories`；新增和修改均可选传 `recentActivity`（近期行为，多行文本，最多 20000 字符，去除首尾空白）；新增默认空字符串，修改时未传保留原值，传 `""` 清空。`list_module_owners` 返回该字段，旧记录默认空字符串；页面列表、编辑弹窗及历史预览同步支持，行为由人工或工具维护，不自动采集。修改另需 `id`、`version`，删除需 `id`、`version`。更新和删除发生版本冲突时必须重新查询。该回调使用每次生成的临时授权，只能操作绑定来源模板，并校验具体活动工具请求；不能用普通接口令牌调用。中断、关闭、切换线程或工具授权撤销后的迟到请求被拒绝。停止 HTTP 服务会撤销当前生成授权。

接口的 `started` 表示任务已提交，表格随成功工具调用更新。每个模板同时只运行一个生成任务。HTTP 超时不自动重试，请打开会话列表确认已有任务；已成功写入的数据不会因中断或失败自动撤销。

负责人数据、生成配置和每次修改的单负责人历史（操作前后内容）保存在 Electron `userData/agent-token-stats.sqlite3` 的负责人专用表中。首次升级自动将原 `module-owners.json` 完整导入 SQLite，原文件保留为备份且不再更新；迁移失败会报错并保留原数据。历史标记手工／AI 来源，AI 修改关联会话 ID。顶部「历史记录」保留当前模板的总览；负责人列表每行的「历史记录」仅按该负责人 ID 查询并展示历史，改名后仍关联原有记录。行内弹窗默认选中最新记录，查询失败可重试；旧版整表快照仅在总览显示。选择历史后预览该负责人的操作前后内容，点击「恢复此负责人」并确认即可恢复新增／修改后的内容，删除记录则恢复删除前内容，其他负责人不受影响，同时新增单负责人恢复历史。已有整表快照标记为旧版，仅供查看，不再允许恢复。新历史不再保存初始空表快照。生成过程中可手工维护，不能回滚。历史预览后表格发生变化时须重新预览，避免意外覆盖。

本功能只生成负责人记录，不为每个模块另开会话。实际 AI 工具执行、Electron 界面及主题效果需单独运行验收。


## 单个负责人的定时任务

负责人行内点击「定时任务」，可为此负责人维护多项任务。每项任务配置名称、提示词、普通／Plan 模式、周期和注入工具；新任务默认停用，保存后可启用。沿用所属模板的模型配置，首版支持有项目目录的本机 Windows Codex 图形模板，执行前须开启 HTTP 接口服务。

周期支持五段 Cron（分钟、小时、日、月、星期；系统本地时区），支持数字、通配符、列表、范围和步长；星期 0 和 7 均为周日。日与星期同时受限时按任一匹配执行。也支持固定间隔＋次数上限：间隔以分钟配置，60 分钟为一小时，首次在一个间隔后执行。成功提交一次任务计一次；创建失败和重叠跳过不计次数，达到上限自动停用。编辑不重置计数，修改周期或重新启用会重新计算下一次时间。

每次到期通过真实 HTTP 创建新会话，并附带所属负责人当时的 ID、version、模块名称、职责、负责目录和项目工作目录。可选注入 `list_module_owners`（查询当前模板全部负责人）、`update_module_owner`（后端仅允许修改本任务所属负责人）；默认均选中，也可全部取消。修改需使用最新版本，冲突后重新查询；AI 修改继续记录负责人历史。

仅应用运行时调度，退出、重启或休眠期间错过的周期不补跑。同一负责人任一定时会话仍在创建、运行或创建结果未确认时，其他到期任务跳过，不排队；不同负责人可分别执行。会话存在且收到非空最终回复才标记成功，同一会话、线程的后续回合回复也可完成任务。会话存在时暂存接口或回合错误并继续等待，空回复不结束跟踪，负责人仍被占用；会话关闭时标记失败并保留错误，不立即重试。停用和删除任务不会自动关闭已创建的会话，删除任务会撤销工具授权；删除负责人会停用其任务并撤销授权，历史恢复不会自动启用任务。模板删除或不再支持时自动停止任务。

配置、计数、下一次执行时间及最近运行结果保存在现有 SQLite 负责人存储中，不改变负责人业务版本。弹窗提供最近会话入口；临时工具凭据不会写入任务数据。升级后须完整退出并重启 Electron，以加载主进程调度服务。

## 定时任务调用历史

定时任务的最终回复也会独立进入顶部「任务列表」，不受下面的调用历史开关影响；仅升级后的新运行生成任务。手动执行、状态跟踪及作废规则见[任务列表说明](module-owner-work-items.md)。

任务编辑弹窗可勾选“记录到历史记录”，新任务和已有任务默认关闭。开启后，每次实际调用“创建会话实例”保存一条 SQLite 记录，包括实际输入、AI 本轮最终回复、调用时间、结束时间和执行状态；跳过的周期不记录。输入中的接口授权令牌不保存。

在定时任务行内点击“历史记录”，可分页查看并打开详情。关闭记录开关只影响后续调用，已有记录继续保留；失败和中断也会保留，应用重启后未结束记录标记为中断。记录存放在 Electron userData 下的 `agent-token-stats.sqlite3` 中的 `app_module_owner_task_runs` 表，不补录旧调用，不自动清理。

调用历史支持行内逐条删除，确认后永久移除该次调用记录；仅已完成、失败、已中断的记录可删除，创建中、运行中和结果待确认的记录需结束后再删除。删除不影响任务配置或已创建的会话。

页面通过受控 IPC 查询历史，不提供额外 HTTP 历史端点。SQLite 写入失败会在任务状态中显示错误，不会因此重复创建会话。升级后需要完整退出并重新启动 Electron。

定时任务仅可选择 `list_module_owners` 和 `update_module_owner` 工具。旧任务配置中的历史查询工具在加载时移除，其余配置保留。
