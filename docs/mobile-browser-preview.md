# 移动端浏览器预览

在仓库根目录运行 `pnpm dev:mobile:browser`，打开 `http://127.0.0.1:6175`。
该入口仅在 `browser-preview` 模式动态加载内存传输，无需电脑端服务或移动访问密码。
普通 `pnpm dev:mobile` 和生产构建继续连接真实服务。

预览包含终端、图形会话、模板、任务和文件列表，以及用于窄屏验收的长标题、长消息和任务输出。
可模拟会话改名与关闭、模板启动、终端输入回显、任务筛选与执行、详情和执行记录弹窗、文件目录导航与生成文件下载、图形消息发送及历史列表。
所有业务数据均在内存中，刷新后重置；未实现的操作会明确提示。

用浏览器设备模式检查窄屏布局、长文本、弹窗滚动和模拟交互。
此预览不能证明真实 Electron、PTY、SSH、文件系统或 IPC 行为。
