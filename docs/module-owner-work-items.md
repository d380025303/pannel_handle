# 定时结果任务列表

顶部「任务列表」汇总所有模板的负责人定时结果，可按模板、负责人、状态和关键词筛选，每页 20 条。会话实例存在且产生非空最终回复的定时运行自动生成一条待执行任务；失败、中断、空回复、跳过周期不生成。调用历史开关不影响生成，旧历史不补录，相同内容的不同轮次分别生成，重复结束事件不会重复入表。“暂无问题”等回复仍入表，可人工作废。

任务详情保存定时任务 ID、负责人 ID、模板 ID、稳定来源运行 ID、原始最终回复，以及来源会话、线程、回合和当轮负责人／模板／工具快照。原始回复不编辑。数据位于 Electron userData 的 `agent-token-stats.sqlite3`，新增 `app_module_owner_work_items` 与 `app_module_owner_work_item_attempts` 两表，不修改已有调用历史。

## 手动执行

点击行内「执行」或「再次执行」，弹窗展示可编辑的实际提示词、当前模板模型配置和来源工具。提示词默认填入原始最终回复，编辑仅用于本次执行并保存在执行记录中；关闭后重新打开仍使用原始回复。确认后通过真实 `POST /api/v1/session-instances` 创建本机 Windows Codex 图形会话，使用普通模式、当前模板模型及编辑后的提示词，不自动追加负责人上下文。模块负责人定时任务仍保留现有上下文注入。需先开启 HTTP 接口服务；来源模板须支持本机 Windows Codex 图形会话且配置项目目录。

每次执行保存独立记录，包括实际输入与配置、会话／线程／回合、状态、时间、最终回复及错误。临时凭据不会保存。工具授权按该轮定时任务选择重新生成，修改仅限来源负责人。未选择工具时仍能精确跟踪会话。同一负责人有创建中、执行中或待核对任务时禁止启动新手动任务；手动运行期间，该负责人到期定时任务跳过、不排队。

状态包括待执行、创建中、执行中、待核对、已完成、失败、中断、已作废。创建成功只代表执行中，关联会话仍存在且产生非空最终回复才标记已完成。同一会话、线程内的重试或后续回合最终回复也可完成本次执行；完成后不再更新。执行回复仅记入执行历史，不继续生成任务。

## 失败、重启与作废

明确失败、中断、已完成均可再次执行，会创建新会话并保留每次记录。会话仍存在时，接口错误、超时、回合失败和空回复均暂存错误并继续等待，不标记失败，也不解除负责人占用；会话关闭或实例不存在时标记失败并保存暂存错误。尚未确认会话是否创建的超时进入待核对，不自动重试，也不允许直接重复创建。通过「核对结果」检查原会话并确认已结束或不存在，之后标记中断，才能重试；关联会话仍在运行或创建请求还在处理时，后端拒绝解除锁定。

应用重启后未完成执行进入待核对，不自动恢复或重跑。退出时跟踪中断也保留记录。回复入表或执行记录写入失败会提示错误，应用存活期间重试 SQLite 写入，不重跑 AI；若在写入成功前强制退出，未写入数据无法保证恢复。

非活动任务可作废并填写可选原因，保留回复和执行记录；恢复后回到待执行。活动任务和待核对任务不能作废，作废不关闭会话，不支持物理删除。

定时任务停用／删除不影响已经生成的任务；负责人或模板删除后记录仍保留，但不能启动新执行。模板切换到不支持的类型也不能执行。回复超过创建接口 256 KiB 请求体限制时完整保留，执行前明确报错，不截断后提交。

升级须完整退出并重启 Electron。测试和构建不替代真实 Electron、AI 调度和主题／窄窗口验收。
