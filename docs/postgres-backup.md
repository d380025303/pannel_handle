# PostgreSQL 多电脑备份

在「设置 → 数据库备份」为每台电脑填写同一个 PostgreSQL 地址、数据库和账号，设置设备名称及跨电脑备份口令，测试连接后启用自动备份。应用首次连接时自动创建 `ph_` 前缀的数据表，因此该账号需要在目标 schema 创建表的权限。服务器使用受信任的 TLS 证书时保持证书验证开启。

会话库仍保存在本机 `userData/sessions.json`，Token 统计仍保存在本机 `userData/agent-token-stats.sqlite3`。启用后，应用在启动、数据变化和每五分钟检查一次备份；断线后会在下次检查时重试。每台安装有独立设备 ID，复制配置到另一台电脑且本机安全存储无法解密时会生成新 ID，并要求重新设置数据库凭据。

Token 统计的时间范围可选择「自定义」，填写开始、结束日期后点击「查询」。自定义范围按北京时间（UTC+8）自然日计算，包含结束当天，可与 Agent 类型、来源电脑组合筛选。升级前的 UTC 日汇总按原日期近似保留，查询涉及这些数据时会提示日期边界可能有误差；升级后新记录的用量增量按北京时间汇总。尚未升级的电脑备份使用旧日汇总近似查询。原有近 7 天、近 30 天和全部时间的统计口径保持不变。

自定义范围内的 Token 总量、趋势和 Agent 用量对比取自每日增量汇总；会话数和明细按最后更新时间筛选，会话 Token 明细及 Skill/MCP 调用仍展示这些会话的累计值。北京时间日汇总及迁移标记随统计数据一起备份，无需手动修改远端表结构。

会话快照整体使用备份口令加密，包含可移植的 SSH 凭据及会话环境变量。数据库密码和备份口令通过本机系统安全存储保存。恢复到另一台电脑时，选择来源设备及快照，输入该快照创建时使用的备份口令，以新 ID 导入会话模板。修改口令后会创建采用新口令的快照，旧快照仍需旧口令。**统计明细与 Agent 对话消息在数据库中可直接读取**，请限制数据库账号的访问权限。

Agent 历史采集使用应用现有历史读取能力，按已启动会话的工作路径扫描。已记录的 Windows 路径在会话关闭后仍可继续扫描；SSH 和 WSL 历史需要对应会话在线。无法访问的来源会在状态中提示，并在重新连接后补传。数据库保留历史快照；本机删除会话或清空统计不会自动删除远端。需要清理远端时，在设置页选择来源电脑并确认删除；删除当前电脑的备份也会关闭其自动备份。
