# 任务自动化

在桌面端“任务列表”中打开“自动化配置”。新增规则、设置条件并启用后保存，已有和新生成的待执行任务都会参与匹配。新建规则默认停用；多个规则按顺序匹配，采用第一条命中的规则。

条件组可以选择“全部满足（且）”或“任一满足（或）”，最多嵌套 5 层。例如：来源模板等于指定项目，且（回复全文包含“修复”或“补充测试”）。文本匹配区分大小写，匹配回复全文而非列表摘要。来源模板、负责人按 ID 匹配。

提示词留空时使用任务原始回复。自定义提示词可插入 `{{output}}`、`{{taskName}}`、`{{ownerName}}`、`{{templateName}}`。保存前可预览匹配数量和前 5 条展开后的提示词；预览针对当前规则，不扣除前序规则的命中。

自动任务全局串行执行，同一负责人已有运行或待核对任务时等待其释放。HTTP 接口未启动时等待接口服务启动。失败、中断、待核对任务不自动重试，每个任务只自动执行一次；人工仍可再次执行。禁用规则不终止已开始的任务。

自动执行创建的新会话，在最终回复和执行结果保存成功、会话状态已完成、关联回合一致且没有待确认事项时自动关闭。来源会话、人工执行会话、模板和执行历史保留。

执行过程中的命令非零退出码、工具调用失败和可恢复错误，不写入自动化错误记录、不提醒，也不阻止最终成功后的自动关闭；会话原始内容及底层诊断日志保留。仅最终执行失败、创建失败、结果保存失败或关闭失败时，显示应用内提醒并尝试系统通知，记录最终错误并保留会话。最终结果以执行系统状态及最终回复是否成功保存为准。历史记录不清理，已保留的历史会话不追溯自动关闭。

应用重启不重复提交已自动执行的任务，不关闭恢复的历史会话。恢复为待核对的自动执行会暂停后续自动任务，需人工核对解除。
