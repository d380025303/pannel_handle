# Agent 会话本地留档

每次通过项目新建或启动 Agent 会话，应用都会在 Electron `userData` 目录中的 `agent-conversations.sqlite3` 创建独立启动记录。相同 CLI 对话被多次启动时，各次启动分别留档；记录包含运行位置、目录、Agent、启动与结束时间、CLI 对话标识和采集状态。

右侧 Agent 对话面板默认读取“本地留档”。关闭会话、重启应用或 SSH 离线后，已保存内容仍可查看。没有活动会话时，面板查询全部目录。来源选择器中的“CLI 原始历史”继续读取 CLI 自己的历史文件或数据库；备份电脑继续读取配置的 PostgreSQL。

图形 Agent 的用户、助手、推理、工具和其他协议条目增量写入 SQLite，流式条目更新同一条消息。附件保存已有文件引用，不复制附件文件。终端 Agent 根据 Hook 提供的 CLI 对话标识，每 5 秒读取现有历史解析器能识别的消息，避免混入同目录其他会话；Gemini 使用历史元数据中的会话标识匹配。终端模式支持 Codex、CodeBuddy、OpenCode、Gemini、Grok 的现有历史读取能力，其余 CLI 只保存启动记录并显示采集限制。

恢复已有 CLI 对话时，图形模式排除提交前加载的历史条目，终端模式排除启动前的消息。功能不会批量导入旧历史。远端不可访问、Hook 未提供标识或 CLI 尚未写出记录时，消息可能暂不可采集，面板显示等待或错误状态。关闭时尽力补读；正常退出应用最多等待 3 秒完成补读，未正常结束的启动记录在下次启动时标记为中断。

留档默认长期保留，不随运行会话关闭而删除。SQLite 保存可读取的对话内容，位于应用本地数据目录；本次功能不上传该留档数据库，原有 PostgreSQL 备份流程保持独立。
