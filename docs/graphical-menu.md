# 图形模式菜单

在桌面端打开 **设置 → 常用配置 → 图形模式菜单**，选择 Agent，勾选要收纳到“其他操作”的项目。未勾选的操作继续展示在“更多操作”的一级菜单中。

每个 Agent 独立保存配置，同一 Agent 的所有会话及连接这台宿主的移动端共享配置。保存后即时生效，手机重新连接时也会获取最新配置。移动端不提供编辑入口。

首次使用及“恢复当前 Agent 默认”均将全部操作留在一级。清单标注两端特有的菜单入口；实际可用项仍取决于 Agent、运行环境和会话状态。移动端 CodeBuddy“会话配置”作为完整入口收纳。

点击“其他操作”进入二级菜单，通过“返回更多操作”回到一级。桌面端可用上下方向键选择操作，右方向键进入二级，左方向键或 Escape 返回一级，再按 Escape 关闭菜单。
